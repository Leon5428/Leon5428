## 构建和恢复

这里的“恢复原首页”指恢复背景图片、README 介绍及卡片布局，**不会自动把中文名称、导航或分类标题改回英文**。
切换布局使用构建参数即可，无需回退整个仓库或覆盖后来更新的文章。

本地查看简洁版，默认使用“潘小工的小屋”：

```powershell
python build.py --simple-home --serve
```

如果后续需要更名，可覆盖默认名称。下列字符串是说明性占位，请替换为实际名称：

```powershell
python build.py --simple-home --site-name "实际申请的网站名称" --serve
```

取得真实备案号后，用 `--icp-number` 指定真实编号，不要在申请前编造编号。
恢复原首页的背景图、README 和卡片，使用相同名称及真实编号，只去掉 `--simple-home`：

```powershell
python build.py --site-name "实际申请的网站名称" --icp-number "实际取得的备案号"
```

当前尚未申请备案，如仅想恢复项目原有本地预览：

```powershell
python build.py --serve
```

首次备案完成前按阿里云要求关闭公网访问；上述 `--serve` 仅监听本机。
本次没有执行服务器配置、域名解析变更、Git 提交或推送。
