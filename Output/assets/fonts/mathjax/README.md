# Article text fonts

Unmodified MathJax Main Regular, Italic and Bold WOFF files from MathJax 3.2.2:

https://github.com/mathjax/MathJax/tree/3.2.2/es5/output/chtml/fonts/woff-v2

The embedded font metadata identifies the copyright as 2009-2010 Design Science,
Inc., with Reserved Font Name MathJax_Main, under the SIL Open Font License 1.1.
See LICENSE.txt for the copyright notice and full font license.

article.css registers these files as "Leon TeX" for Latin article text only.
Chinese text retains the existing serif fallback; code retains its monospace font.
MathJax's SVG formula renderer and version are unchanged. Mathematical variables
in source documents must still be enclosed in math delimiters, such as $s$.
